# Pardeep Kumar — React Native Developer Portfolio

A personal portfolio highlighting Pardeep Kumar's mobile development experience, technical skills, and selected projects.

**Live site:** [pkaypilania.github.io/pardeep-kumar](https://pkaypilania.github.io/pardeep-kumar/)

## About the project

The site is a responsive single-page application built with React. It includes an introduction, work experience, skills, project details, and contact information. Project cards link to relevant app stores, websites, and repositories where available.

## Built with

- React 18
- Vite
- Tailwind CSS
- Lucide React

## Run locally

```bash
git clone https://github.com/pkaypilania/pardeep-kumar.git
cd pardeep-kumar
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Run ESLint |

## Deployment

Pushing to `main` triggers the GitHub Actions workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). It builds the site and publishes the `dist/` directory to the `gh-pages` branch for GitHub Pages.
